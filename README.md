# ApexPlanet Internship Task 2: EDA & Business Intelligence

## Project Overview
This project analyzes sales data to identify revenue trends, product performance, category performance, and customer patterns.

## Tools Used
- Python and Jupyter Notebook
- Pandas for data cleaning and exploratory data analysis
- MySQL for business queries
- Microsoft Excel for dashboard visualization
- GitHub for project documentation

## Project Contents
- `ApexPlanet_Task2_EDA.ipynb` — data cleaning and exploratory analysis
- `ApexPlanet_Task2.sql` — SQL queries and business analysis
- `ApexPlanet_Task2_Dashboard.xlsx` — sales dashboard
- `apexplanet_cleaned_sales.csv` — cleaned dataset

## Key Findings
- Electronics generated the highest revenue among product categories.
- Mobile was the leading product by quantity sold.
- Patna recorded the highest city revenue.
- Customers aged 35–44 contributed the highest revenue among age groups.

## Deliverables
The project includes the cleaned data, analysis notebook, SQL queries, and Excel dashboard.
